algorithm clamp.
given v - real number, v finite, v not NaN,
      l - lower boundary,
      u - upper boundary,
find  v' - real number in [l, u].

model:      sequential
terminates: yes

[decide]           C0. [guard.]       if v not finite return None.  (v finite.)   -> C1
[compute + Decide] C1. [Sswap.]        if l > u swap l <-> u.         (l ≤ u.)      -> C2
[compute + Decide] C2. [lower bound.] if v < l set v <- l.          (v ≥ l.)      -> C3
[compute + Decide] C3. [upper bound.] if v > u set v <- u.          (v ∈ [l,u].)  -> done

verify
termination:  4 fixed steps, no loop
correctness:  v ∈ [l,u] holds after C3
invariant:    v finite at C2 · l ≤ u at C2 · v ≥ l at C3
